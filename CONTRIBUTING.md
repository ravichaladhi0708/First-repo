## Code of Conduct

Please note that this project adheres to the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## How Can I Contribute?

There are many ways to contribute:

1. **Reporting Bugs** – Use the issue tracker to report bugs. Provide a clear description, steps to reproduce, and any relevant logs or screenshots.
2. **Suggesting Enhancements** – Open an issue to discuss new features or improvements before creating a pull request.
3. **Pull Requests** – Submit PRs for bug fixes, new features, documentation updates, or refactoring.

## Reporting Bugs

- Search existing issues to ensure the bug hasn't already been reported.
- Include a descriptive title and detailed description.
- Provide environment details (OS, Python version, etc.) and steps to reproduce.

## Suggesting Enhancements

- Search existing issues to avoid duplicates.
- Clearly describe the proposed change and its benefits.
- Include any relevant design considerations or alternatives.

## Pull Request Process

1. **Fork the repository** and create a new branch for your changes.
2. **Write clear, concise commit messages**. Follow the conventional commit format if possible.
3. **Ensure the code passes all tests**. Add tests for new functionality.
4. **Update documentation** if your change affects usage.
5. **Submit the PR** targeting the `main` branch of the original repository.
6. **Address review feedback** promptly.

## Style Guidelines

- Follow the project's existing coding style (PEP 8 for Python files).
- Use meaningful variable and function names.
- Keep line lengths to a maximum of 88 characters.
- Run `flake8` and `black` (or the configured formatter) before submitting.

## Testing

- Run existing tests with `pytest` to ensure nothing is broken.
- Add unit tests for new functionality.
- Ensure test coverage does not decrease.

## Documentation

- Keep documentation up-to-date with code changes.
- Use Markdown for README and other docs.
- Add examples where appropriate.
